# ArmorTest

**3D Tank Armor Range** — test armor packages against everything from oyster shells to air-to-surface missiles and drones.

## Features

- **10 modern MBTs** (default: M1A2 Abrams)
- **10 armor packages** (stock → ERA → APS → experimental nanocomposite)
- **20 projectiles** ranging from hand-thrown oyster shells to AGM-65 Maverick and loitering munitions
- **Country flag backdrop** that switches with the selected tank
- Procedural low-poly 3D tanks + impact effects
- BobloxClassic font throughout

## How to run

Just open `index.html` in a modern browser (Chrome / Firefox / Edge).  
Or enable GitHub Pages on this repo and visit the Pages URL.

## Controls

- Drag to orbit the tank
- Scroll to zoom
- Pick tank / armor / projectile from the left panel
- Hit **FIRE!**

## Notes

Penetration numbers are simplified RHA-equivalent estimates for gameplay, not doctrinal tables. APS has a chance to intercept missiles and drones.

Built for the ArmorTest repo.
